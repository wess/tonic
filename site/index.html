Installation

After downloading and verifying the bundle:

tar -xzf tonic0.0.1.macosarm64.tar.gz
cd tonic0.0.1
bash install.sh "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
tonic run hello.exs

Compile with clang/LLVM 18+. Mix projects also require Elixir 1.18 / OTP 27. Linux builds require glibc 2.39+.

!

Know the boundaries

Distributed BEAM, hot code loading, arbitrary NIFs, custom dependency build managers, and umbrella root builds are outside this release.
